# Free Tools Website — Content & SEO Plan

## Overview

A WordPress site offering **free online tools** that people use for work and fun.
Monetization-ready (ads, affiliate, newsletter) and built entirely from
client-side HTML/CSS/JS so no backend or API cost is required.

## Why these tools win

- **High search volume, low competition** — "word counter", "password generator",
  "age calculator" are searched millions of times per month.
- **Instant use** — visitors use the tool immediately, no signup = high dwell time
  and low bounce rate (Google loves this).
- **Shareable** — fun tools (typing test, decision maker, palette generator)
  get shared on social media = free backlinks.
- **Work tools** build trust and return visits; **fun tools** earn shares.
  A mix of both compounds traffic.

## Keyword strategy

- Target **long-tail** keywords first: "free random password generator",
  "how many words in a paragraph", "morse code translator with sound".
- Each post should naturally contain the primary keyword 3-5 times (title,
  intro, one heading, body, FAQ).
- Add an **FAQ section** (pick 4-6 real questions people ask) — FAQ blocks
  earn featured snippets in Google.

## Site architecture (WordPress)

- **Posts** vs **Pages**: publish each tool as a **Page** with the tool embedded
  at top, OR a **Post** if you plan a blog. Recommendation: use **Pages** for
  tools (clean URLs: /word-counter/, /password-generator/) and a **Blog** for
  extra articles linking to tools.
- **Category structure**:
  - Work Tools (Calculators, Text Tools, Generators)
  - Fun Tools (Games, Random Generators, Creativity)
- Recommended plugins:
  - **Rank Math SEO** (free) — SEO titles, sitemap, schema
  - **WP Rocket** or **LiteSpeed Cache** (free) — speed
  - **Insert HTML Snippet** or use the built-in **Custom HTML block**
  - **Table of Contents Plus** — adds TOC, good for SEO
- Theme suggestion: lightweight theme (GeneratePress, Astra, or Blocksy) for
  fast load times.

## Content formula per tool post

1. H1 title with the tool name + keyword
2. The **tool itself** (embedded, above the fold)
3. Short "How to use" (3 steps, bullet list)
4. "Features" section (bullet list with emoji-free checkmarks)
5. "Why use this tool / who it's for" (2-3 short paragraphs)
6. FAQ (4-6 questions) in HTML `<details>` blocks for featured snippets
7. Related-tools links (internal linking between the 10 tools = SEO boost)
